## 주)엘핀

- 📍 **Revit (구 컨셉)** (2026.07.08 ~ 2026.07.24 · 위치 기반 여행 기록 앱) — 촬영 위치에 24시간 잠금을 걸고 반경 내 재방문 인증으로 해제하는 "재방문 잠금 타임캡슐" 컨셉을 설계·구현. GPS/네트워크 이중 측위 기반 백그라운드 위치 트래킹 파이프라인과 여행 세션(시작~자동 종료·이동거리 계산) 생명주기를 직접 구축했고, 오프라인 상황을 고려한 위치 로그 로컬 큐잉·재전송 처리로 네트워크 불안정 환경에서도 데이터 유실 없이 동작하도록 안정성을 확보. Supabase RLS 기반 사용자별 데이터 격리 스키마도 직접 설계.

## 주)제이예스

- 🗂️ **WIZ 데이터 구축** — 공공 API + 크롤링으로 전국 행정동 3,560개 상권 데이터 수집, 정규화 DB 스키마 단독 설계
- 📊 **WIZ-Report** — 인구·매출 등 8개 이상 지표를 점수화해 업종 127개 소분류별 상권 추천 시스템 구축
- 🎨 **WIZ 마켓** — GPT·Gemini·Imagen3로 텍스트+이미지를 합성해 SNS 콘텐츠를 3단계(선택→생성→공유)로 자동 생성
- 📱 **WIZ 마켓 Android 앱** — 외주 중단 상태의 WebView 하이브리드 앱을 JS↔Native 메시지 라우팅부터 재구현, 양대 스토어 정식 출시
- 🔐 **인프라 배포/운영** — DB 외부 노출 이슈를 Docker 네트워크 분리 + 허용 IP 기반 접근 제어로 해결
