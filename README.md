## 지금까지 한 일

데이터 수집 → 정제/설계 → 해석(점수화·추천) → 생성형 AI 콘텐츠 → 앱 출시까지, **상권 데이터 서비스(WIZ)** 의 전 과정을 혼자 맡아 만들었습니다.

**2024.08 – 2025.12 · 제이예스 주식회사 · WIZ 서비스 풀스택 개발** (DB 설계 / BE / FE / Android)

## 기술 스택

| 영역 | 사용 기술 |
|---|---|
| **Backend** | Python, FastAPI, Java (Spring Boot, JPA) |
| **Frontend** | React (JavaScript), Canvas |
| **Mobile** | Android (Kotlin), WebView, JavaScript Bridge |
| **DB / Infra** | RDBMS (정규화 스키마 설계), Alibaba Cloud, Docker, HTTPS(SSL) |
| **Etc** | 공공 API, 크롤링, OCR, 생성형 AI (GPT, Gemini, Imagen3) |

## 주요 프로젝트

- 🗂️ **WIZ 데이터 구축** — 공공 API + 크롤링으로 전국 행정동 3,560개 상권 데이터 수집, 정규화 DB 스키마 단독 설계
- 📊 **WIZ-Report** — 인구·매출 등 8개 이상 지표를 점수화해 업종 127개 소분류별 상권 추천 시스템 구축
- 🎨 **WIZ 마켓** — GPT·Gemini·Imagen3로 텍스트+이미지를 합성해 SNS 콘텐츠를 3단계(선택→생성→공유)로 자동 생성
- 📱 **WIZ 마켓 Android 앱** — 외주 중단 상태의 WebView 하이브리드 앱을 JS↔Native 메시지 라우팅부터 재구현, 양대 스토어 정식 출시
- 🔐 **인프라 배포/운영** — DB 외부 노출 이슈를 Docker 네트워크 분리 + 허용 IP 기반 접근 제어로 해결
