## 주)엘핀

- 📍 **Zari** (2026.07~ · 위치 기반 SNS) — 사진 찍은 위치에 핀을 꽂아 지도에서 추억을 공유하는 위치 기반 SNS. 클러스터링 지도 UI와 리렌더 성능 최적화, iOS(APNs 직통)/Android(FCM) 좋아요 푸시 알림 직접 구현, Supabase(Postgres/Storage/Edge Functions) 기반 백엔드 설계를 담당.
- 📍 **Revit (구 컨셉)** (2026.07 · 위치 기반 여행 기록 앱) — 촬영 위치에 24시간 잠금을 걸고 반경 내 재방문 인증으로 해제하는 "재방문 잠금 타임캡슐" 컨셉을 설계·구현. GPS/네트워크 이중 측위 기반 백그라운드 위치 트래킹 파이프라인과 여행 세션(시작~자동 종료·이동거리 계산) 생명주기를 직접 구축했고, 오프라인 상황을 고려한 위치 로그 로컬 큐잉·재전송 처리로 네트워크 불안정 환경에서도 데이터 유실 없이 동작하도록 안정성을 확보. Supabase RLS 기반 사용자별 데이터 격리 스키마도 직접 설계.

## 주)제이예스

- 🗂️ **WIZ 데이터 구축** — 공공 API + 크롤링으로 전국 행정동 3,560개 상권 데이터 수집, 정규화 DB 스키마 단독 설계
- 📊 **WIZ-Report** — 인구·매출 등 8개 이상 지표를 점수화해 업종 127개 소분류별 상권 추천 시스템 구축
- 🎨 **WIZ 마켓** — GPT·Gemini·Imagen3로 텍스트+이미지를 합성해 SNS 콘텐츠를 3단계(선택→생성→공유)로 자동 생성
- 📱 **WIZ 마켓 Android 앱** — 외주 중단 상태의 WebView 하이브리드 앱을 JS↔Native 메시지 라우팅부터 재구현, 양대 스토어 정식 출시
- 🔐 **인프라 배포/운영** — DB 외부 노출 이슈를 Docker 네트워크 분리 + 허용 IP 기반 접근 제어로 해결

## 개인

- 🎮 **[로그라이트 오토배틀러](https://github.com/tpals213/RogueLike)** (프로토타입) — 죽어도 안 사라지는 메타 자원(다이아)으로 영구 성장하는 로그라이트 + 오토배틀 게임. 전투는 100% 자동 진행, 플레이어는 장비/시너지 세팅과 맵 경로 선택에만 개입. 콘솔·tcod GUI·Kivy(모바일) 세 진입점이 게임 로직(`game/`)을 완전히 공유하도록 설계했고, Kivy 버전은 `buildozer`로 안드로이드 APK 빌드까지 확인. 3개 장(Act) 구성 노드맵, 장비 7슬롯·시너지 5종·유물 21종 시스템, 허브 성장 트리를 Python만으로 구현 — 유료 서비스/DB 없이 로컬 JSON 저장만으로 동작.
